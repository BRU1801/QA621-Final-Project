## Тестовые наборы данных и ожидаемые результаты

Для подтверждения корректности работы предусмотрены интеграционные тесты:

1. **`data/users.csv`** (22 записи)
   - Ожидаемое количество нарушений: **7**
   - Ошибки включают: некорректный email, пустое имя (required), возраст вне диапазона (range), дубликат ID (unique), недопустимая роль (one_of), некорректный тип возраста (type), дубликат email (unique).
2. **`data/orders.json`** (21 запись)
   - Ожидаемое количество нарушений: **6**
   - Ошибки включают: дубликат order_id (unique), null user_id (required), отрицательная сумма (range), нулевая сумма (range), пустой order_id (required/length), недопустимый промокод (one_of).
